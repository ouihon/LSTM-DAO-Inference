Getting Started

Welcome to AI Magnetic Design

AI Magnetic Design is a comprehensive platform for designing and optimizing magnetic components, particularly DC-AC converters. This system combines advanced neural network models with intuitive design tools to help engineers create efficient magnetic components.

Key Features

  • Interactive design center with real-time parameter adjustment
  • Pre-trained neural network models for various magnetic materials
  • Custom model training and fine-tuning capabilities
  • Comprehensive visualization of magnetic properties
  • Export models in multiple formats (.h5, .json, .pdf)

System Requirements

  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • JavaScript enabled
  • Internet connection for initial load
  • Recommended: 1920x1080 or higher resolution

Design Center

Overview

The Design Center is the main workspace for designing magnetic components. It provides interactive controls for adjusting core parameters and visualizing the resulting magnetic behavior.

Core Parameters

  • R (Outer Radius): The outer radius of the toroidal core, measured in mm
  • r (Inner Radius): The inner radius of the toroidal core, measured in mm
  • d (Height/Thickness): The height or thickness of the toroidal core, measured in mm
  • N (Number of Turns): The number of wire turns in the winding
  • Effective Cross-Sectional Area (Ae): Automatically calculated as Ae = (R - r) × d, displayed in cm²
  • Effective Magnetic Path Length (Le): Automatically calculated as Le = π × (R + r), displayed in mm
  • Inductance (L): For materials 3C90, 3C94, 3E6, and 3F4, the inductance is automatically calculated based on the core geometry and relative permeability (μᵣ), displayed in mH

Visualization Tools

The Design Center provides several real-time visualization charts:

  • Grid & Inverter Voltage: Dual-axis chart showing grid voltage (left Y-axis) and inverter voltage (right Y-axis) over time
  • Inductor Voltage & Flux Linkage: Dual-axis chart showing inductor voltage V_L (left Y-axis) and flux linkage (right Y-axis). You can select a region by clicking and dragging to trigger AI predictions
  • Core Loss Comparison: Bar chart comparing core loss across different materials. Click bars to view B-H curves
  • Magnetic Flux Density (B): Displays the magnetic flux density characteristics for selected materials
  • Field Strength (H): Shows the magnetic field strength, updated based on AI predictions when a flux region is selected

Chart Synchronization & Interaction

The Grid & Inverter Voltage chart and Inductor Voltage & Flux Linkage chart are synchronized for better analysis:

  • Synchronized Zoom: When you zoom (mouse wheel) on either chart, both charts zoom together, keeping their x-axes aligned. This ensures consistent time scales across both visualizations.
  • Synchronized Pan: When you pan (drag) either chart horizontally, both charts pan together, maintaining synchronized time ranges.
  • Draggable Handle: On the Grid & Inverter Voltage chart, a blue draggable handle appears when you hover over the chart. You can drag this handle left or right to pan the view, and both charts will update simultaneously.
  • Flux Selection Reset: When you zoom, pan, or drag on either chart, any previously selected flux region will be automatically reset. This ensures that flux selections remain valid for the current view.

Note: The flux selection bounding box resets automatically when:

  • Zooming on either chart (mouse wheel or pinch gesture)
  • Panning either chart (drag or keyboard)
  • Dragging the handle on the voltage chart
  • Changing operating conditions or parameters

Operating Conditions

Configure inverter and grid parameters:

  • Topology: Select DC-AC converter topology (Single-Phase Full Bridge, 3Phase Full Bridge, or 3Phase T-Type Three-Level)
  • DC Voltage: Input DC voltage (200-800V)
  • Frequency: Switching frequency (5-100kHz)
  • Filter Parameters: Filter inductance (L) and capacitance (C)
  • Grid Parameters: Grid voltage, frequency, power, and impedance
  • Harmonics: Inject 3rd, 5th, and 7th harmonic components

Using the Design Center

  1. Configure operating conditions (topology, voltages, frequencies)
  2. Select and configure materials from the Material & Core Design panel
  3. Adjust core parameters (R, r, d, N) for each material. Ae, Le, and L (for first four materials) are automatically calculated
  4. Observe real-time updates in the visualization charts
  5. Select a region in the Flux chart to trigger AI predictions for B-H curves
  6. Compare core losses across different materials
  7. Fine-tune parameters to achieve desired performance

Grid-Connected DC-AC Inverter Simulation

Overview

The Design Center includes a comprehensive time-domain simulation model for grid-connected inverters. This simulation captures the dynamic behavior of voltage, current, and inductor flux under PWM operation. The simulation is intended for educational demonstration, algorithm prototyping, and qualitative performance evaluation, rather than device-level design.

System Architecture

The simulated system consists of:

  • Ideal DC voltage source
  • PWM-controlled inverter bridge
  • Grid-side filter inductor (L)
  • Equivalent grid voltage source with optional harmonic distortion
  • Power-based closed-loop modulation control with PI controller

Supported Topologies

  • Single-Phase Full Bridge: Two-level PWM inverter for single-phase grid connection
  • 3Phase Full Bridge: Three-phase two-level PWM inverter
  • 3Phase T-Type Three-Level: Three-phase three-level T-type inverter with Phase Disposition (PD) PWM

Grid Voltage and Harmonic Modeling

The grid voltage is modeled as a sinusoidal source:

vg(t) = V̂ · sin(ωt + φ)

For three-phase systems, a fixed 120° phase displacement is applied. To emulate non-ideal grid conditions, the model allows injection of 3rd, 5th, and 7th harmonic components, specified as a percentage of the fundamental magnitude. Random initial phase angles are assigned to each harmonic to avoid artificial symmetry.

PWM and Inverter Output Modeling

The inverter employs Sinusoidal PWM (SPWM):

  • The modulation reference is synchronized with the grid frequency
  • A symmetric triangular carrier is used
  • Both two-level and three-level (PD-PWM) strategies are supported

For three-phase three-wire systems, common-mode voltage is explicitly accounted for, ensuring realistic phase voltage representation. Output voltage levels are automatically scaled according to the selected topology and DC-link voltage.

Power Control and Modulation Adjustment

A power-based PI controller adjusts the modulation index to regulate the delivered active power. The control law can be expressed as:

Δm = Kp(P* − P) + Ki∫(P* − P)dt

where P* is the power reference and P is the instantaneous calculated power.

  • Kp (Proportional Gain): Default value 0.00004, adjustable via slider in the Operating Conditions panel
  • Ki (Integral Gain): Default value 0.8, adjustable via slider in the Operating Conditions panel
  • Power reference (P*) and actual power (P) are continuously monitored
  • This approach enables qualitative assessment of power tracking dynamics under different grid and filter conditions

Inductor Current and Flux Computation

The filter inductor dynamics follow:

vL = vinv − vg − i·R

Inductor current is updated discretely as:

i(t+Δt) = i(t) + (vL/L)·Δt

In addition, the inductor magnetic flux is obtained by integrating the inductor voltage:

ψ(t+Δt) = ψ(t) + vL·Δt

This allows visualization and analysis of flux accumulation and low-frequency drift phenomena, which are relevant for studying DC bias effects and control robustness.

Numerical Simulation and Data Output

The simulation runs over multiple grid cycles with a time step determined by the switching frequency and carrier resolution. To balance accuracy and performance, results are stored using down-sampling.

The following waveforms are available as outputs:

  • Grid voltage (v_grid)
  • Inverter output voltage (v_inv)
  • Inductor voltage (v_L)
  • Inductor current (i_L)
  • Inductor magnetic flux (flux_L)
  • Normalized PWM signal

These outputs can be used for waveform visualization, harmonic analysis, and comparative studies across different configurations.

Model Assumptions

The following assumptions are adopted:

  • Passive components are linear and time-invariant
  • Power semiconductor devices are ideal (no switching loss or dead-time effects)
  • Grid frequency is constant
  • Grid voltage harmonics (3rd, 5th, and 7th order) can be optionally superimposed
  • State updates are performed using an explicit Euler integration method

Applicability and Limitations

This model is intended as a behavioral-level inverter simulation. It does not represent switching losses, thermal effects, or electromagnetic parasitics, and therefore should not be used for detailed hardware design.

The modular structure allows future extensions, such as:

  • LCL filter modeling
  • dq-frame control strategies
  • Inner current control loops
  • Non-ideal switching and dead-time effects

Model Libraries

Pre-trained Models

The Model Libraries section provides access to pre-trained neural network models for various magnetic materials. These models have been trained on extensive datasets and are ready for immediate use.

Available Material Models

  • 3C90: High-frequency ferrite material, suitable for switching power supplies
  • 3C94: Advanced soft magnetic material with low core loss
  • 3E6: Non-crystalline magnetic material with excellent high-frequency properties
  • 3F4: Composite material with distributed air gaps
  • Custom Model: User-trained models for specific applications

Model Information

Each model displays key information:

  • Number of parameters (~6K typical)
  • LSTM hidden size: 40
  • MLP hidden size: 16
  • Training dataset size

Selecting a Model

  1. Navigate to the Model Libraries section
  2. Review available models and their specifications
  3. Select the model that best fits your application
  4. The selected model will be loaded into the Design Center

Model Training

Training Custom Models

The Model Training section allows you to fine-tune existing models or train new models using your own datasets. This is useful for specialized applications or materials not covered by pre-trained models.

Training Process

  1. Prepare Dataset: Create a ZIP file containing three CSV files: H.csv, T.csv, and B.csv
  2. Upload Data: Use the file upload interface to upload your ZIP file. The system will validate the data format and dimensions
  3. Select Base Model: Choose a pre-trained model (A-E) as starting point
  4. Configure Hyperparameters: Set epochs, learning rate, batch size, window stride, loss function, and frozen layers
  5. Start Training: Training runs asynchronously. Monitor progress through real-time metrics and charts
  6. Validate Results: Review loss curves, RMSE, and Energy Loss metrics for both training and validation sets
  7. Export Model: Download trained weights and training report PDF

Dataset Format

Your dataset must be a ZIP file containing exactly three CSV files:

  • H.csv: Magnetic field strength data, shape (N, M) where N is number of samples, M is time series length
  • B.csv: Magnetic flux density data, shape (N, M) matching H.csv
  • T.csv: Temperature data, shape (N, 1) where N matches H and B

All three files must have the same number of samples (N). Data is loaded using comma-separated values.

Hyperparameters

  • Epochs: Number of complete passes through the dataset (10-1000)
  • Learning Rate: Step size for weight updates (0.0001-0.1)
  • Batch Size: Number of samples per training step (8-128)
  • Validation Split: Fraction of data used for validation (0.1-0.4)
  • Window Stride: Sliding step size for window creation. Window size is fixed at 1000 points (1-1000)
  • Loss Function: Choose from MSE, RMSE, or Energy Loss
  • Frozen Layers: Number of initial layers to freeze during fine-tuning (0-3)

Training Metrics

During training, you can monitor:

  • Training/Validation Loss: Real-time loss curves with blue (training) and green (validation) lines
  • RMSE: Root Mean Square Error percentage for both training and validation sets
  • Energy Loss: Energy density normalized error percentage for both training and validation sets
  • Initial Model Comparison: Comparison metrics showing improvement over the base pre-trained model
  • Training Time: Elapsed time and average time per epoch

Export & Integration

Export Options

The platform supports multiple export formats to integrate models into your workflow.

Export Options

After training completes, you can download:

  • Model Weights (.sd): Trained model weights in PyTorch format, ready for inference
  • Training Report (.pdf): Comprehensive PDF report containing:
    • Training and validation loss curves
    • RMSE progress charts
    • Energy Loss progress charts
    • Training summary with all hyperparameters and final metrics

File Retention

Uploaded data and training results are automatically retained for 15 days. A scheduled task runs daily at midnight to clean up files older than 15 days.

Troubleshooting

Common Issues

Model Not Loading

  • Check browser console for error messages
  • Verify model file format is correct
  • Ensure sufficient memory is available
  • Try refreshing the page

Training Fails

  • Verify dataset format matches requirements
  • Check for missing or invalid data points
  • Reduce batch size if memory errors occur
  • Lower learning rate if training diverges

Poor Prediction Accuracy

  • Ensure input parameters are within valid ranges
  • Check if selected model matches your material
  • Consider training a custom model with your data
  • Verify measurement data quality
