Getting Started

Welcome to AI Magnetic Design

AI Magnetic Design is a comprehensive platform for magnetic component design and analysis. The platform provides two complementary workflows:

Test Center

New

For rapid AI-powered analysis of measured magnetic data. Upload B-field CSV files (16 MHz sampling) and instantly predict H-field and core losses.

Best for: Testing existing components, comparing materials, high-speed data analysis

Design Center

For interactive simulation and design of magnetic components. Configure operating conditions, adjust core geometries, and visualize real-time behavior.

Best for: New component design, topology simulation, parameter optimization

System Requirements

  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • JavaScript enabled
  • Internet connection for AI prediction API (Test Center)
  • Recommended: 1920x1080 or higher resolution

Test Center New Feature

Overview

The Test Center provides rapid AI-powered analysis of magnetic measurements. Upload your measured B-field data (sampled at 16 MHz), select materials, and receive instant predictions of H-field and core losses without running time-consuming simulations.

Workflow

  1. Upload B Data: Import a CSV file containing magnetic flux density (B) measurements (single line, comma-separated)
  2. Set Temperature: Adjust operating temperature (0-100°C) using the slider; changes trigger automatic re-prediction
  3. Select Materials: Choose one or more materials to compare (3C90, 3C94, 3E6, 3F4, or Other Material)
  4. AI Prediction: The system automatically sends data to the AI model and retrieves H-field predictions
  5. View Results: Analyze B-H curves and compare core losses across different materials under identical B-field conditions

Data Format Specification (B.csv)

The input file must be a single-line CSV file with comma-separated values representing magnetic flux density:

0.0012,0.0015,0.0018,0.0021,0.0024,...,0.0010
  • Format: Single row only, no headers, comma-separated
  • Unit: Tesla (T) - not milliTesla
  • Decimal: Use dot (.) as decimal separator
  • Length: Flexible, typically 1,000 to 100,000 points

Sampling Frequency & Time Parameters

Test Center is optimized for high-speed magnetic measurements:

Sampling Frequency 16 MHz 16,000,000 samples/second
Sampling Period (Δt) 6.25×10⁻⁵ ms 62.5 nanoseconds per point
Total Time Calculation T = (N - 1) × 6.25×10⁻⁵ ms N = number of data points

Important: The AI model expects data sampled at exactly 16 MHz. If your measurement uses a different sampling rate, you must resample the data before upload, or the loss calculations will be incorrect.

Temperature Control

The temperature slider allows you to specify operating conditions:

  • Range: 0°C to 100°C
  • Default: 25°C (room temperature)
  • Auto-update: Changing temperature automatically triggers AI re-prediction with new thermal parameters
  • Effect: Influences both H-field prediction magnitude and core loss calculation

Material Selection

Click material buttons to select/deselect them for analysis. Multiple materials can be compared simultaneously:

  • 3C90: High-frequency ferrite (μᵣ ≈ 2300) - for switching supplies up to 500 kHz
  • 3C94: Low-loss ferrite (μᵣ ≈ 4000) - reduced losses at elevated temps
  • 3E6: High-permeability ferrite (μᵣ ≈ 6000) - for high inductance applications
  • 3F4: Power ferrite (μᵣ ≈ 1000) - for frequencies up to 1 MHz
  • Other Material: Generic baseline for comparison

Analysis Results

Test Center provides three visualization panels:

  • Core Loss Comparison (W): Horizontal bar chart showing predicted total power loss in Watts for each selected material. Calculated using AI-predicted H-field and B-field integration over the time period.
  • Magnetic Flux Density B (T): Time-domain display of the uploaded B-field data. All materials share the same input B curve.
  • Field Strength H (A/m): AI-predicted H-field response for each selected material. Different materials produce different H curves due to varying permeability and core loss characteristics.

Loss Calculation Method

Core losses are calculated using energy integration over the B-H loop:

P = (1/T) × ∫ H(t) × (dB/dt) dt

Where T is the total time period calculated as N × 6.25×10⁻⁵ ms. The integration is performed numerically using the AI-predicted H sequence and the uploaded B sequence. Results are displayed in Watts (W) representing total power dissipation.

Design Center

Overview

The Design Center is the main workspace for designing magnetic components with real-time simulation capabilities. Unlike the Test Center (which analyzes existing data), the Design Center simulates inverter operation and calculates magnetic behavior based on circuit parameters and core geometries.

Core Parameters

  • R (Outer Radius): The outer radius of the toroidal core, measured in mm (Range: 10-500)
  • r (Inner Radius): The inner radius of the toroidal core, measured in mm (Range: 5-400)
  • d (Height/Thickness): The height or thickness of the toroidal core, measured in mm (Range: 5-2000)
  • N (Number of Turns): The number of wire turns in the winding (Range: 5-200)
  • Effective Cross-Sectional Area (Ae): Automatically calculated as Ae = (R - r) × d / 100, displayed in cm²
  • Effective Magnetic Path Length (Le): Automatically calculated as Le = π × (R + r), displayed in mm
  • Inductance (L): For materials with known permeability (3C90, 3C94, 3E6, 3F4), inductance is automatically calculated based on core geometry: L = (μ₀ × μᵣ × N² × (R-r) × d) / (π × (R+r) × 1000), displayed in mH

Operating Conditions

Configure inverter and grid parameters for simulation:

  • Topology: Select DC-AC converter topology
    • Single-Phase Full Bridge
    • 3Phase Full Bridge
    • 3Phase T-Type Three-Level
  • DC Voltage: Input DC voltage (200-800V)
  • Switching Frequency: Inverter switching frequency (5-100kHz)
  • Filter Inductance (L): Grid-side filter inductance in mH (0-1.5)
  • Filter Capacitance (C): Filter capacitance in μF (0-20)
  • Grid Voltage: AC grid voltage in V (110-380)
  • Grid Frequency: Grid frequency in Hz (50-60)
  • Power: Target power output in W (0-15000)
  • Grid Impedance: Line impedance in Ω (0-1)
  • Harmonics: Optional injection of 3rd, 5th, and 7th harmonics (0-5%)

Visualization Charts

  • Grid & Inverter Voltage: Dual-axis chart showing grid voltage (cyan) and inverter output voltage (orange) over time. Includes draggable handle for panning both synchronized charts.
  • Inductor Voltage & Flux Linkage: Shows inductor voltage V_L (green) and magnetic flux linkage (yellow). Supports click-and-drag selection to trigger AI predictions on selected flux regions.
  • Core Loss Comparison: Bar chart comparing core loss across different materials. Click bars to activate materials for B-H curve visualization.
  • Magnetic Flux Density (B): Displays B-field characteristics calculated from selected flux regions.
  • Field Strength (H): AI-predicted H-field based on B and material properties.

Flux Selection for AI Prediction

In the Inductor Voltage & Flux Linkage chart:

  1. Click and drag horizontally to select a region of the flux curve
  2. The selected region is highlighted with an orange bounding box
  3. The system automatically calculates B = Flux / (Ae × N)
  4. AI prediction is triggered to generate corresponding H-field
  5. Core losses are calculated based on the selected region
  6. Note: Selection clears when zooming or panning charts

Chart Synchronization

The voltage and flux charts are synchronized for consistent analysis:

  • Zoom Sync: Zooming (mouse wheel) on either chart synchronizes both x-axes
  • Pan Sync: Horizontal panning on either chart updates both views simultaneously
  • Draggable Handle: Blue vertical handle on voltage chart allows synchronized panning of both charts
  • Auto-reset: Any zoom/pan operation resets the flux selection to ensure data validity

Power Control Parameters

The simulation includes a PI controller for power regulation:

  • Kp (Proportional Gain): Default 0.00004, adjustable range 0-0.0001
  • Ki (Integral Gain): Default 0.8, adjustable range 0-2
  • Controller adjusts modulation index to track target power: Δm = Kp(P* - P) + Ki∫(P* - P)dt

Simulation Details

The Design Center runs a time-domain circuit simulation with the following characteristics:

  • Simulation Duration: 5 grid cycles
  • Time Step: Determined by switching frequency (100 steps per switching period)
  • Integration Method: Explicit Euler for inductor current and flux linkage
  • PWM Strategy: Sinusoidal PWM (SPWM) with triangular carrier
  • Three-Level Modulation: Phase Disposition (PD) PWM for T-Type topology

Model Libraries

Pre-trained Models

The platform provides pre-trained neural network models for common ferrite materials. These models are used by both the Test Center (for file analysis) and the Design Center (for flux selection analysis).

Available Material Models

3C90 - High-frequency Mn-Zn ferrite

Relative permeability μᵣ ≈ 2300. Optimized for switching power supplies and DC-AC converters operating up to 500 kHz.

3C94 - Low-loss Mn-Zn ferrite

Relative permeability μᵣ ≈ 4000. Features reduced core losses at elevated temperatures, suitable for high-efficiency designs.

3E6 - High-permeability Mn-Zn ferrite

Relative permeability μᵣ ≈ 6000. Designed for applications requiring high inductance with minimal turns.

3F4 - Power Mn-Zn ferrite

Relative permeability μᵣ ≈ 1000. Optimized for power applications at frequencies up to 1 MHz.

Other Material - Generic placeholder

Used for baseline comparison or when specific material properties are unknown. No automatic inductance calculation.

Model Architecture

  • Type: LSTM (Long Short-Term Memory) Neural Network with MLP output layers
  • Parameters: ~6,000 trainable parameters per model
  • LSTM Hidden Size: 40 units
  • MLP Hidden Size: 16 units
  • Input Features: B-field sequence, Temperature (°C), Time span (seconds)
  • Output: H-field sequence (A/m), Core loss (W)

Temperature Dependence

All models account for temperature effects on magnetic properties (0-100°C range). The neural network learns the non-linear relationship between temperature, B-field, and resulting H-field including core loss mechanisms.

Model Training

Training Custom Models

Train custom neural network models using your own measured magnetic data. This is useful for proprietary materials or specific temperature ranges not covered by pre-trained models.

Dataset Format

Upload a ZIP file containing exactly three CSV files with matching dimensions:

  • H.csv: Magnetic field strength in A/m, shape (N, M)
  • B.csv: Magnetic flux density in Tesla, shape (N, M)
  • T.csv: Temperature in Celsius, shape (N, 1)

Where N is the number of samples and M is the time series length. All three files must have the same number of samples (N). Data is loaded using comma-separated values.

Training Process

  1. Upload ZIP file containing H.csv, B.csv, T.csv
  2. Select a base pre-trained model (A-E) for transfer learning
  3. Configure hyperparameters (epochs, learning rate, batch size, etc.)
  4. Start training - runs asynchronously with real-time progress
  5. Monitor loss curves, RMSE, and Energy Loss metrics
  6. Download trained model weights (.sd) and training report (.pdf)

Hyperparameters

Epochs 10 - 1000 Number of complete passes through dataset
Learning Rate 0.0001 - 0.1 Step size for gradient descent optimization
Batch Size 8 - 128 Samples processed before weight update
Validation Split 0.1 - 0.4 Fraction of data reserved for validation
Window Stride 1 - 1000 Sliding window step (window size fixed at 1000)
Loss Function MSE / RMSE / Energy Loss Optimization objective
Frozen Layers 0 - 3 Number of initial layers frozen during fine-tuning

Training Metrics

  • Training/Validation Loss: Real-time loss curves (blue = training, green = validation)
  • RMSE: Root Mean Square Error percentage vs. baseline model
  • Energy Loss: Core loss prediction accuracy metric

Transfer Learning

When selecting a base model, the system uses transfer learning to accelerate convergence:

  • Base model weights are loaded as starting point
  • Frozen layers preserve low-level feature extraction
  • Unfrozen layers adapt to new material characteristics
  • Particularly effective for materials similar to base ferrites

Export & Integration

Export Options

Export trained models and analysis results for external use.

Model Export

  • Model Weights (.sd): PyTorch state dictionary containing trained parameters. Compatible with PyTorch for deployment in Python environments.
  • Training Report (.pdf): Comprehensive document including:
    • Training and validation loss curves
    • RMSE and Energy Loss progress charts
    • Hyperparameter configuration table
    • Final performance metrics
    • Training time and convergence statistics

API Integration (Test Center)

The Test Center uses the following REST API endpoint for predictions. You can integrate this into your own applications:

POST /api/predict
Content-Type: application/json

{
  "materialId": 1,
  "sample": {
    "B": [0.001, 0.002, ...],  // Array of B values in Tesla
    "T": 25,                    // Temperature in Celsius
    "real_time": 0.0625        // Total time in seconds
  }
}

Response:

{
  "H_pred": [12.5, 13.2, ...],  // Predicted H values in A/m
  "core_loss": 2.34             // Predicted loss in Watts
}

Data Retention Policy

Uploaded files and training results are automatically retained for 15 days. A scheduled task runs daily at midnight UTC to purge files older than 15 days. Important results should be downloaded before expiration.

Troubleshooting

Common Issues

Test Center: "No valid data found in file"

  • Ensure the CSV is single-line format (no row headers)
  • Check that values are comma-separated without extra spaces
  • Verify decimal points use dots (.) not commas
  • Ensure file extension is .csv and encoding is UTF-8
  • Check that B values are in Tesla, not milliTesla

Test Center: Incorrect Loss Values

  • Verify data was sampled at 16 MHz (6.25×10⁻⁵ ms intervals)
  • If using different sampling rate, resample data before upload
  • Ensure complete periods are included (minimum 3-5 cycles)
  • Check temperature setting matches measurement conditions

Design Center: Simulation Not Updating

  • Check that R > r (outer radius must be larger than inner radius)
  • Verify all parameters are within valid ranges
  • Ensure DC voltage > Grid voltage for proper operation
  • Check browser console for JavaScript errors

AI Prediction Failed

  • Check internet connection to API endpoint
  • Reduce data points if request times out (>500k points may fail)
  • Verify material ID is valid (1-5)
  • Check browser console for detailed error messages

Performance Tips

  • Test Center: For large datasets (>100k points), consider downsampling to improve prediction speed
  • Design Center: If browser becomes slow, reduce switching frequency or select fewer materials
  • General: Clear browser cache if charts fail to render or display outdated data
  • Mobile: Use desktop browser for best experience; mobile view is limited
